# Lecture 6 illustrations and numerical fixtures, version 1

**Student-site copy.** Generator and canonical-source paths below refer to the sibling `STAT709-html-conversion` preparation repository. Rights are described in the [hosting notice](../../../../README.md#third-party-notices).


Original course illustrations generated by `scripts/lecture6-figures.mjs` using
`assets/js/widgets/lecture6-views.mjs`. The five SVGs illustrate the canonical
softmax, factor rotation, order-statistic window, uniform maximum (solution
only), and information-processing discussions. No external artwork is copied.
`figures.json` binds all files to the canonical source hash and source tiers.

`maxima-bank.json` contains 200 × 12 prefix maxima, produced from 200 consecutive
trials of 10000 standard-normal observations, seed 709, using the existing
`stat709-mulberry32-boxmuller-v1` profile. Generator attribution remains in
`assets/js/primitives/random.mjs` and `catalog/randomness-profile.json`.
The values are synthetic teaching samples, not observed course/student data.

The model module's 5th/50th/95th percentile reference ratios were calculated
with Python `statistics.NormalDist.inv_cdf(exp(log(q)/n))/sqrt(2*log(n))`.
All 36 values were checked through `Phi(value*sqrt(2*log(n)))**n` with absolute
residual below 2e-12. They are distribution quantiles, not confidence intervals.
Runtime settings are restricted to the twelve validated sample sizes.

Interactive default plots and numeric readouts are generated inline using the
same model functions; print/no-script preserves those initial-state drawings.
The widget contract and actual verification are recorded in COMPONENTS.md and
docs/LECTURE-6-HTML.md, respectively.
