# Lecture 4 illustrations, version 1

Original vector drawings generated by `scripts/lecture4-figures.py` from the approved examples in `source_lectures/lect-4.tex`. No external art or third-party license is involved. The course repository’s ownership and licensing terms apply; this adds no new license grant. `figures.json` records exact source labels, solution-only placement, descriptions, and SHA-256 hashes.

Each panel uses a local sans-serif font fallback. Panels stack on narrow screens; no JavaScript is needed. The original source, its formulas, and the complete solutions remain authoritative.
