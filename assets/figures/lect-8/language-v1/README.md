# Published GloVe analogy figure

**Student-site copy.** Generator and canonical-source paths below refer to the sibling `STAT709-html-conversion` preparation repository. Rights are described in the [hosting notice](../../../../README.md#third-party-notices).


`glove-man-woman.jpg` is the unchanged figure from the official
[GloVe project](https://nlp.stanford.edu/projects/glove/), under “Linear
substructures,” by Jeffrey Pennington, Richard Socher, and Christopher D. Manning.
The associated [2014 paper](https://aclanthology.org/D14-1162/) is cited in the
lecture. The canonical caption retains the author credit and project link.

The plot shows learned word vectors, including man/woman and king/queen pairs.
It illustrates approximate parallel semantic offsets; it does not prove the
covariance assumptions of the lecture's random factor model. This is published
research artwork, not a synthetic course example.

The project page licenses its code under Apache 2.0 and its released vectors
under PDDL. It does not state a separate license for this website figure, and
we do not apply either code/data license to the image. No new license is asserted.
The instructor requested this attributed scholarly illustration. Exact source,
download date, byte hash, and status are retained in `provenance.json`.

A future HTML conversion should preserve the visible caption and provide alt
text describing the approximate parallel offsets. No HTML component is implemented.
