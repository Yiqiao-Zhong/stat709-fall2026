# Lecture 3 web figure derivatives

Generated by [lecture3-web-figures.py](../../../../scripts/lecture3-web-figures.py) from the six approved [version 1 SVGs](../v1/README.md). The originals, canonical source, and PDF previews remain unchanged.

Each complete SVG uses an explicit Arial/sans-serif fallback for browsers without DejaVu Sans. Fourteen panel SVGs retain the original paths, values, titles, legends, and axis scales, grouped by column. In the mixed RN figure each column keeps its atomic and continuous rows together. Shared glyph definitions are retained. The lecture displays the complete figure on wide screens and stacks these panels at 650px or below; print uses the complete figure.

[panels.json](panels.json) records each original SHA-256, complete web derivative, panel files, and their hashes. The builder verifies these before copying them to `dist/`. The standalone builder embeds the derivatives as data URLs. No external art, script, font service, or extra client library is loaded.

These are original course figures under the same [rights policy](../../../../RIGHTS.md) as their sources. No new public license is assigned. Regenerate from the repository root with:

```sh
python3 scripts/lecture3-web-figures.py
```

The additional shrinking-spike sketch is generated directly by `scripts/lecture3-support.mjs` from the labeled source example, with n=1,4,16, fixed axes, width 1/n, height n, and area one. Its three vector panels stack on narrow screens; it is not a slider or a simulation.
