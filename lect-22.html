◆ High priorityOverview

A test addresses a specified hypothesis about the parameter. A confidence set reports the values that remain compatible with the data under a chosen procedure.

Both constructions need calibration: a statement about how the procedure behaves under repeated sampling.

We first obtain exact coverage from Normal sampling laws and pivots. Then the CLT, Slutsky’s theorem, and likelihood expansions give approximate coverage and approximate test levels.

Reminder only: this block introduces no new exam requirements.

  • Level and error control. A level-\(\alpha\)α\alpha test has rejection probability at most \(\alpha\)α\alpha at every null parameter. Used in test inversion.

  • The CLT and Slutsky’s theorem. A Normal limit can survive replacement of an unknown scale by a consistent estimate. Used to construct approximate intervals.

  • Fisher information. Information measures the local sensitivity of the model to its parameter. Used to scale the MLE and compare efficiency.

1. Confidence sets and coverage

◆ High priorityWhat a confidence level means

Let \(X\sim P_\theta\)X∼PθX\sim P_\theta, \(\theta\in\Theta\)θ∈Θ\theta\in\Theta, and let \(\tau(\theta)\)τ(θ)\tau(\theta) be the quantity of interest. A lower confidence bound \(L(X)\)L(X)L(X) satisfies \(P_\theta\{L(X)\leq\tau(\theta)\}\geq1-\alpha\)Pθ{L(X)≤τ(θ)}≥1−αP_\theta\{L(X)\leq\tau(\theta)\}\geq1-\alpha for every \(\theta\)θ\theta; an upper confidence bound is defined with the reverse inequality.

For a procedure satisfying this definition, \(1-\alpha\)1−α1-\alpha is a guaranteed lower bound, and actual coverage can be larger. A nominal level attached to an approximate interval need not be a finite-sample guarantee; Section 4 states the corresponding limiting claim.

The probability statement concerns \(C(X)\)C(X)C(X) before observing the sample.

After observing \(X=x\)X=xX=x, the reported set \(C(x)\)C(x)C(x) is fixed. Frequentist coverage does not by itself assign probability \(1-\alpha\)1−α1-\alpha to the fixed parameter lying in that particular reported set.

3. The duality between tests and confidence sets

◆ High priorityCollect the values that are not rejected

For every proposed target value \(t\)tt, consider a nonrandomized test \(\varphi_t(X)\in\{0,1\}\)φt(X)∈{0,1}\varphi_t(X)\in\{0,1\} of \(H_{0,t}:\tau(\theta)=t\)H0,t:τ(θ)=tH_{0,t}:\tau(\theta)=t, with \(1\)11 meaning rejection. The null may be composite because other components of \(\theta\)θ\theta are unspecified. Assume that every test has level \(\alpha\)α\alpha over its null: \[\sup_{\theta:\tau(\theta)=t}P_\theta\{\varphi_t(X)=1\}\leq\alpha.\]supθ:τ(θ)=tPθ{φt(X)=1}≤α.\sup_{\theta:\tau(\theta)=t}P_\theta\{\varphi_t(X)=1\}\leq\alpha.

Theorem 1Test–confidence-set duality; BD’s Duality Theorem, p. 243

The set \(C(X)=\{t:\varphi_t(X)=0\}\)C(X)={t:φt(X)=0}C(X)=\{t:\varphi_t(X)=0\} is a level-\((1-\alpha)\)(1−α)(1-\alpha) confidence set for \(\tau(\theta)\)τ(θ)\tau(\theta). Conversely, a level-\((1-\alpha)\)(1−α)(1-\alpha) confidence set produces level-\(\alpha\)α\alpha tests by rejecting \(t\)tt exactly when \(t\notin C(X)\)t∉C(X)t\notin C(X).

Proof. For any true parameter \(\theta\)θ\theta, the two events \(\{\tau(\theta)\notin C(X)\}\){τ(θ)∉C(X)}\{\tau(\theta)\notin C(X)\} and \(\{\varphi_{\tau(\theta)}(X)=1\}\){φτ(θ)(X)=1}\{\varphi_{\tau(\theta)}(X)=1\} are identical. Hence \[P_\theta\{\tau(\theta)\in C(X)\} =1-P_\theta\{\varphi_{\tau(\theta)}(X)=1\}\geq1-\alpha.\]Pθ{τ(θ)∈C(X)}=1−Pθ{φτ(θ)(X)=1}≥1−α.P_\theta\{\tau(\theta)\in C(X)\} =1-P_\theta\{\varphi_{\tau(\theta)}(X)=1\}\geq1-\alpha. Read the same identity in reverse for the converse. ◻

We are inverting a family of tests, one for every proposed value, while keeping the observed data fixed.

We need not separately correct for multiple testing to obtain this coverage statement: at a fixed true \(\theta\)θ\theta, noncoverage is exactly rejection of the one true target value.

This is the duality argument, not a claim about simultaneous truth of all possible conclusions. See also the complementary explanation in [2].

4.1. An approximate pivot

◆ High priorityNormal limits and estimated standard errors

An exact pivot is often unavailable. Key ideas

  • Coverage describes a random set under repeated sampling; the parameter is fixed.

  • Exact pivots give finite-sample coverage. Approximate pivots require a limit argument and a reliable standard error.

  • Inverting level-\(\alpha\)α\alpha tests gives a level-\((1-\alpha)\)(1−α)(1-\alpha) confidence set for the tested target.

  • Regular likelihood theory connects information, efficient estimation, and Wald, score, and likelihood-ratio tests.

  • Chi-square degrees of freedom come from the model’s constraints; exact and asymptotic calibrations must remain distinct.
