Lecture 2 supplied measurable sets, measures, and random variables. We now build integration with respect to a measure and study the theorems that make the construction useful. The main practical question is: \[\textit{When may a limit, sum, derivative, or iterated integral be exchanged with integration?}\]𝑊h𝑒𝑛 𝑚𝑎𝑦 𝑎 𝑙𝑖𝑚𝑖𝑡, 𝑠𝑢𝑚, 𝑑𝑒𝑟𝑖𝑣𝑎𝑡𝑖𝑣𝑒, 𝑜𝑟 𝑖𝑡𝑒𝑟𝑎𝑡𝑒𝑑 𝑖𝑛𝑡𝑒𝑔𝑟𝑎𝑙 𝑏𝑒 𝑒𝑥𝑐h𝑎𝑛𝑔𝑒𝑑 𝑤𝑖𝑡h 𝑖𝑛𝑡𝑒𝑔𝑟𝑎𝑡𝑖𝑜𝑛?\textit{When may a limit, sum, derivative, or iterated integral be exchanged with integration?} The answer is never “because the expressions look well behaved.” Each exchange requires assumptions that control signs, monotonicity, or magnitude.

  • Applications. For example, an average loss can be written as an integral against an empirical measure, a population risk is an integral against a probability law, and a likelihood calculation may require differentiating an integral.

  • Common language. The same notation should handle a finite sum, a continuous density, and a law containing both point masses and a continuous part.

  • Workflow. We will build this common language first, then ask which assumptions justify each exchange.

1. Abstract integration

◆ High priorityDefinitions and integral rules used throughout statistics

Throughout this section, \((\Omega,\F,\nu)\)(Ω,ℱ,ν)(\Omega,\mathcal{F},\nu) is a measure space. We use \[\mathbf 1_A(\omega)=\mathbf 1\{\omega\in A\}\]1A(ω)=1{ω∈A}\mathbf 1_A(\omega)=\mathbf 1\{\omega\in A\} for an indicator function. Definition 1Integral of a nonnegative simple function

Definition 2Integral of a nonnegative function

For a nonnegative measurable function \(f:\Omega\to[0,\infty]\)f:Ω→[0,∞]f:\Omega\to[0,\infty], define \[\int f\,d\nu = \sup\left\{\int\phi\,d\nu: 0\le\phi\le f,\ \phi\text{ simple and measurable}\right\}.\]∫fdν=sup{∫ϕdν:0≤ϕ≤f,ϕ simple and measurable}.\int f\,d\nu = \sup\left\{\int\phi\,d\nu: 0\le\phi\le f,\ \phi\text{ simple and measurable}\right\}. For a real-valued measurable function \(f\)ff, define \[f^+=\max(f,0),\qquad f^-=\max(-f,0).\]f+=max(f,0),f−=max(−f,0).f^+=\max(f,0),\qquad f^-=\max(-f,0). Then \[f=f^+-f^-, \qquad |f|=f^++f^-.\]f=f+−f−,|f|=f++f−.f=f^+-f^-, \qquad |f|=f^++f^-.

A measurable function \(f\)ff is integrable with respect to \(\nu\)ν\nu if \[\int|f|\,d\nu<\infty.\]∫|f|dν<∞.\int|f|\,d\nu<\infty. Almost everywhere and almost surely.

  • Meaning. A property holds almost everywhere (a.e.) with respect to \(\nu\)ν\nu if it fails only on a zero-measure set, also called a null set: a measurable set \(N\)NN with \(\nu(N)=0\)ν(N)=0\nu(N)=0. We write \(\nu\)ν\nu-a.e. when the measure needs to be explicit. For a probability measure \(P\)PP, the corresponding phrase is almost surely (a.s.).

  • Countable statements. The exceptional set is understood to be contained in a measurable null set; all functions in our integral statements are measurable. Countably many a.e. statements can be enforced simultaneously because a countable union of null sets is null.

  • Warning. The same conclusion need not hold for an uncountable family of null sets. For example, every singleton in \([0,1]\)[0,1][0,1] has Lebesgue measure zero, while their union has measure one.

The abstract notation packages several familiar operations.

  • Measure and notation. When \(\nu=m\)ν=m\nu=m is Lebesgue measure on \(\R^d\)ℝd\mathbb{R}^d, write \[\int_{\R^d}f(x)\,dx \quad\text{instead of}\quad \int_{\R^d}f\,dm.\]∫ℝdf(x)dxinstead of∫ℝdfdm.\int_{\mathbb{R}^d}f(x)\,dx \quad\text{instead of}\quad \int_{\mathbb{R}^d}f\,dm.

  • Measure and sum. On \(\N\)ℕ\mathbb{N}, let \(\nu_{\mathrm{count}}\)νcount\nu_{\mathrm{count}} denote counting measure. Then \[\int_{\N}a(k)\,d\nu_{\mathrm{count}}(k) = \sum_{k=1}^{\infty}a(k)\]∫ℕa(k)dνcount(k)=∑k=1∞a(k)\int_{\mathbb{N}}a(k)\,d\nu_{\mathrm{count}}(k) = \sum_{k=1}^{\infty}a(k) whenever the nonnegative or absolutely convergent expression is defined.

1.1. Connection between Lebesgue integrals and Riemann integrals

◇ Low priority—not examined: Riemann comparison and the fundamental theorem

Let \(m\)mm be Lebesgue measure on \([a,b]\)[a,b][a,b] (completed when needed). The abstract integral preserves the familiar calculus rules, while enlarging the class of integrable functions. The following four connections make this precise.

  1. Agreement where the Riemann integral exists. If \(f\)ff is Riemann integrable on \([a,b]\)[a,b][a,b], it is Lebesgue integrable and \[\mathop{\mathrm{Riemann}}\int_a^b f(x)\,dx =\int_{[a,b]}f\,dm.\]Riemann∫abf(x)dx=∫[a,b]fdm.\mathop{\mathrm{Riemann}}\int_a^b f(x)\,dx =\int_{[a,b]}f\,dm. Indeed, the Lebesgue integral lies between the lower and upper step-function sums, whose difference tends to zero. See [2] (Theorem 11.33) for a full proof.

  2. The criterion for Riemann integrability. A bounded function on \([a,b]\)[a,b][a,b] is Riemann integrable if and only if it is continuous almost everywhere: its set of points of discontinuity has Lebesgue measure zero. Piecewise continuous functions with finitely many pieces satisfy this criterion. A proof is given in Labute’s notes on Lebesgue’s integrability criterion.

  3. Differentiating an indefinite integral. If \(f\)ff is Lebesgue integrable on \([a,b]\)[a,b][a,b] and \[F(x)=\int_a^x f(t)\,dt,\]F(x)=∫axf(t)dt,F(x)=\int_a^x f(t)\,dt, then \(F'(x)=f(x)\)F′(x)=f(x)F'(x)=f(x) for Lebesgue-a.e. \(x\in(a,b)\)x∈(a,b)x\in(a,b). Thus an integral still recovers the integrand by differentiation, with an a.e. qualification. In fact, \(F\)FF is absolutely continuous; this function property is specified below.

  4. Integrating a derivative. If \(F\)FF is differentiable at every point of \([a,b]\)[a,b][a,b] (with one-sided derivatives at endpoints) and \(F'\)F′F' is Lebesgue integrable, then \[F(b)-F(a)=\int_a^b F'(t)\,dt.\]F(b)−F(a)=∫abF′(t)dt.F(b)-F(a)=\int_a^b F'(t)\,dt. This is the valid everywhere-differentiability statement in the original notes; see [3] (Theorem 7.21). It must not be weakened to “differentiable almost everywhere” without another condition.

Theorem 1Monotone convergence theorem (MCT)

Let \(f_1,f_2,\ldots\)f1,f2,…f_1,f_2,\ldots and \(f\)ff be nonnegative measurable functions. If \(f_n\uparrow f\)fn↑ff_n\uparrow f \(\nu\)ν\nu-a.e., then \[\int f\,d\nu = \lim_{n\to\infty}\int f_n\,d\nu,\]∫fdν=limn→∞∫fndν,\int f\,d\nu = \lim_{n\to\infty}\int f_n\,d\nu, where either side may equal \(+\infty\)+∞+\infty.

  • Conditions. MCT requires nonnegativity and monotone increase, but it does not require an integrable upper bound.

  • Truncation. Choosing the theorem.

  • If \(0\le f_n\uparrow f\)0≤fn↑f0\le f_n\uparrow f, first try MCT.

  • If \(f_n\to f\)fn→ff_n\to f and there is one integrable envelope \(g\)gg, use DCT.

  1. Cantor function · Low — not examined
