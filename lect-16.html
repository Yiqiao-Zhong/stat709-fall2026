1.2. Matrix norms

◆ High priorityMatrix norms

There are many different matrix norms we encounter. Here are a few common norms. Let \(A \in \R^{m \times n}\)A∈ℝm×nA \in \mathbb{R}^{m \times n} denote a generic matrix.

  • Frobenius norm \(\left\|A\right\|_F = (\sum_{ij}A_{ij}^2)^{1/2}\)∥A∥F=(∑ijAij2)1/2\left\|A\right\|_F = (\sum_{ij}A_{ij}^2)^{1/2}. Essentially, we treat \(A\)AA as a vector of length \(mn\)mnmn and then use the Euclidean norm. Frobenius norm can be expressed using singular values \(\left\|A\right\|_F^2=\sum_{j=1}^r[\sigma_j(A)]^2\)∥A∥F2=∑j=1r[σj(A)]2\left\|A\right\|_F^2=\sum_{j=1}^r[\sigma_j(A)]^2.

  • Operator norm \(\left\|A\right\|_{\mathrm{op}} = \sigma_1(A)\)∥A∥op=σ1(A)\left\|A\right\|_{\mathrm{op}} = \sigma_1(A), and by convention, simply \(\left\|A\right\|\)∥A∥\left\|A\right\| unless specified otherwise. It can be shown that \(\left\|A\right\|_{\mathrm{op}} = \max_{u:\left\|u\right\|_2=1} \left\| Au\right\|_2\)∥A∥op=maxu:∥u∥2=1∥Au∥2\left\|A\right\|_{\mathrm{op}} = \max_{u:\left\|u\right\|_2=1} \left\| Au\right\|_2.

  • Matrix \(p\)pp-norm \(\left\|A\right\|_{p} = \max_{u:\left\|u\right\|_p=1} \left\| Au\right\|_p\)∥A∥p=maxu:∥u∥p=1∥Au∥p\left\|A\right\|_{p} = \max_{u:\left\|u\right\|_p=1} \left\| Au\right\|_p. See also Wiki for a comprehensive comparison.

Operator norm.

The operator norm is the largest singular value and controls the largest stretch over all unit input vectors. The Frobenius norm is the square root of the sum of squared singular values.

For \(A=\operatorname{diag}(3,4)\)A=diag(3,4)A=\operatorname{diag}(3,4), compute \(\|A\|_{\rm op}\)∥A∥op\|A\|_{\mathrm{op}}, \(\|A\|_F\)∥A∥F\|A\|_F, and \(\|A\|_{\max}\)∥A∥max\|A\|_{\max}. Explain what each norm measures and which values coincide.

Reveal solution

The singular values are 4 and 3, so operator norm is 4 and Frobenius norm is \(\sqrt{16+9}=5\)16+9=5\sqrt{16+9}=5. The largest absolute entry is 4. The Frobenius norm accumulates all squared entries; the operator norm measures the largest directional stretch.

Exercise 6A volumetric covering argument#

Prove that an \(\epsilon\)ϵ\epsilon-net of the Euclidean unit ball in \(\R^n\)ℝn\mathbb{R}^n can be chosen with at most \((1+2/\epsilon)^n\)(1+2/ϵ)n(1+2/\epsilon)^n points.

Take a maximal \(\epsilon\)ϵ\epsilon-separated set in the ball.
